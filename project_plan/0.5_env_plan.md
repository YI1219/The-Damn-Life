# 个人自动化助手 V0.5 最终项目计划书

## 项目定位

**一句话**：一个普通人能用自然语言控制自己电脑的私人助手，像聊天一样简单，像管家一样可靠，能看懂任何软件和网页。

**核心承诺**：
- 🗣️ **自然语言优先**：所有操作、权限管理、审计查询都用对话完成，不用记命令、不用写配置
- 🔒 **隐私安全**：数据全在本地，你随时可以一键清除，所有操作都先问你
- 📱 **手机遥控**：躺在床上也能让电脑干活，支持 P2P 直连，不需要公网 IP
- 💻 **全平台覆盖**：Windows、Mac、Linux 都能用，能控制浏览器、软件、文件系统
- 👁️ **看得懂一切**：能读取任何网页内容（包括动态加载的），能操作任何软件界面

## 第一部分：用户故事

### 故事 1：小白第一次用

```
1. 下载安装包，双击安装（30秒搞定）
2. 手机上打开助手网页，扫码配对（10秒）
3. 开始聊天：“帮我整理下载文件夹”

不需要：
❌ 写配置文件
❌ 记任何命令
❌ 懂技术术语
❌ 看教程
```

### 故事 2：日常使用

```
你（躺在床上）：“帮我打开浏览器，搜索一下明天北京的天气”

助手：
“好的，正在打开浏览器...
 🌐 已打开 Chrome
 🔍 正在搜索“北京 天气 明天”
 
 明天北京天气：
 🌡️ 温度：15-22°C
 ☀️ 天气：晴转多云
 🌬️ 风力：2-3级
 
 需要我帮你记录到日程吗？”
```

### 故事 3：操作网页

```
你正在看 Gmail：
“帮我把未读的邮件总结一下”

助手：
“好的，我看到 3 封未读邮件：

1. 张三 (10:23) - “明天的会议改到下午3点”
2. 李四 (09:15) - “项目文档已更新”
3. 王五 (昨天) - “邀请你参加周五分享会”

要回复哪一封吗？”

你：“回复第一封，说收到”
助手：“✅ 已发送回复”
```

### 故事 4：动态页面

```
你在淘宝看商品：
“帮我盯着这个商品，降价了告诉我”

助手：
“好的，我会每隔 5 分钟检查一次。
 当前价格：¥299
 目标：低于 ¥250 时通知你
 需要我同时关注库存吗？”

你：“好的，没货也告诉我”
助手：“✅ 已设置监控”
```

### 故事 5：权限管理

```
你想让助手整理桌面：

你：“让助手可以整理我的桌面”

助手：
“好的，这需要允许访问桌面文件夹。
 你想：
 A) 只这一次
 B) 以后都可以”

你：“只这一次”

助手：
“✅ 已设置。本次会话结束后会自动取消权限。
 放心，我不会乱动你的文件。
 
 顺便提醒，桌面有 23 个文件，
 要现在整理吗？”
```

### 故事 6：查审计

```
你：“上周谁动了我的文件？”

助手：
“上周有 5 次操作记录：
 
 3月20日 10:23 - 文件整理（你批准的）
   整理下载文件夹，23个文件移到分类文件夹

   打开淘宝，搜索“键盘”

   想删除临时文件，你说“不需要”
 
 要看详细记录吗？可以点这里撤销操作”
```

### 4.1 整体架构图

```

└─────────────────────────────────────────────────────────────┘
                              │
                              │ WebRTC (P2P直连，不用公网IP)
                              │ WebSocket (局域网/备选)
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                  电脑端：主控服务 (Node.js)                   │
│  • Fastify + WebSocket + WebRTC                             │
│  • SQLite (审计、配置、对话记录)                             │
│  • 会话管理 + 任务队列                                       │
│  • 权限审批 + 审计记录                                       │
│  • 浏览器扩展通信                                            │
└─────────────────────────────────────────────────────────────┘
                    │                           │
                    ▼                           ▼
┌─────────────────────────────┐ ┌─────────────────────────────┐
│     Skill 执行器 (Python)    │ │     浏览器扩展 (JS)          │
│  • 文件系统操作              │ │  • 读取当前页面              │
│  • 进程管理                  │ │  • 监听DOM变化               │
│  • 模拟输入（pyautogui）     │ │  • 执行点击/填表             │
│  • 跨平台适配层              │ │  • 支持动态内容              │
│  • 系统通知                  │ │  • 支持编辑器                │
└─────────────────────────────┘ └─────────────────────────────┘
```

### 4.2 核心技术栈

| 层级 | 技术 | 理由 |
|------|------|------|
| 手机端 | React + TypeScript + Tailwind | PWA跨平台，一套代码跑iOS/Android/Web |
| 手机存储 | IndexedDB | 断网缓存，容量大 |
| 手机通信 | WebRTC + WebSocket | P2P直连，不需要公网IP |
| 电脑主控 | Node.js + TypeScript | WebSocket/WebRTC生态成熟，异步模型适合审批等待 |
| 电脑存储 | SQLite | 单机够用，可导出 |
| Skill执行 | Python 3.10+ | Windows系统操作最成熟，跨平台支持好 |
| 浏览器扩展 | Manifest V3 + TypeScript | Chrome/Edge/Firefox兼容 |
| 动态内容 | MutationObserver + CDP | 等待渲染，支持无限滚动 |

## 第九部分：总结

### 一句话

**做一个人人都能用的电脑助手，像发微信一样指挥电脑干活，能看懂任何软件和网页。**

### 三大核心价值

1. **简单**：用对话代替命令，小白也能用
2. **安全**：所有操作都问你，随时能查能撤销
3. **强大**：能控制文件、软件、浏览器、任何网页

### 技术亮点

- P2P直连，不需要公网IP
- 浏览器扩展，完美读取动态网页
- 跨平台，Windows/Mac/Linux都支持
- 自然语言权限管理，说句话就能改

### 用户体验承诺

- 不用学，用对话就行
- 不用怕，所有操作都问过你
- 不用愁，随时能查能撤销
