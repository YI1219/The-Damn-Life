# The Damn Life 项目计划书 V1.0

> **版本说明**：V1.0 建立在 V0.5 的离线优先个人自动化助手基础上，全面实现**桌宠式交互**、**安全隔离的链接空间**、**内置穿透的远程控制**三大核心能力，形成可远程管理、可直观交互、可完全掌控的 AI 原生个人助手。本版本为产品从“单机可用”迈向“多设备可管”的关键里程碑。

---

## 1. 一句话定位（V1.0）

**可远程控制、可直观交互、安全隔离的个人自动化助手。**

核心承诺（在 V0.5 基础上新增）：
- **远程可触达**：无论身在何处，都能通过 Web、App 或命令行控制家中的 AI 助手，实时查看状态与结果。
- **交互直觉化**：以桌宠浮动窗口为核心，拖拽文件/Skill，环形菜单快速执行，降低使用门槛。
- **安全与隔离**：AI 运行在独立容器中，通过“链接空间”与用户系统安全交互，用户拥有完全控制权。
- **离线优先**：所有核心能力仍保持离线可用，远程控制仅在需要时联网。

---

## 2. V1.0 的产品边界（做与不做）

### 2.1 V1.0 必做（在 V0.5 基础上新增）

- **桌宠交互系统**（Electron 浮动窗口 + 环形菜单 + 拖拽）
- **远程控制体系**（内置内网穿透 + Web UI + REST API + 实时状态推送）
- **安全隔离与链接空间**（容器化 AI + 授权目录/应用白名单 + 用户完全控制面板）
- **多设备同步**（同一账户下多设备的数据同步，可选自建服务器或用户自托管）
- **Skill 市场雏形**（官方 Skill 库，支持在线浏览、一键安装）
- **移动端适配 Web UI**（响应式设计，手机浏览器可完整操作）
- **命令行控制接口**（通过 CLI 发送指令、查询状态）

### 2.2 V1.0 明确不做（推迟到后续版本）

- **多用户账户与权限分级**（V1.0 仅支持单用户）
- **操作系统内核级修改**（V1.0 仍基于现有操作系统，仅用容器/子进程隔离）
- **完整的 P2P 网络**（V2.0+）
- **内容市场与 Token 经济**（V1.5+）
- **语音唤醒/视觉识别**（V2.5+）
- **LoRA 训练**（V1.5+）

> 原则：V1.0 聚焦“远程 + 桌宠 + 安全”三大突破，确保产品可用性、安全性、易用性，为生态扩展打好基础。

## 3. V1.0 核心场景（延续并强化 V0.5 三场景）

### 场景 A：本地文件与信息整理（强化）
- **新增桌宠交互**：拖拽文件到桌宠，环形菜单选择“整理”“归档”“总结”等。
- **远程整理**：在外通过手机上传文件到链接空间，AI 自动整理并通知结果。

### 场景 B：PC 自动化（强化）
- **远程控制**：外出时让 AI 打开家里电脑的特定应用、下载文件、执行脚本。
- **桌宠快捷操作**：通过环形菜单直接调用常用自动化 Skill（如“一键备份”“清理垃圾”）。

### 场景 C：本地日程/提醒（强化）
- **远程创建提醒**：在外通过手机告诉 AI “明天上午提醒我开会”，AI 同步到本地。
- **多设备同步**：在 PC 上创建的提醒，手机端也能查看和接收通知。

> 所有场景依然遵循离线优先：本地操作完全离线，远程操作需要网络但 AI 核心仍在本地执行。

### 4.2 主要模块职责

| 模块 | 职责 | 技术选型建议 |
|------|------|--------------|
| **AI 容器** | 运行本地推理引擎、Skill Runtime，与宿主隔离 | Docker（Windows/Linux），资源限制可配置 |
| **链接空间** | 授权目录映射、应用白名单、权限校验 | 通过 Docker 卷映射 + 配置管理 |

| **数据存储** | 对话记录、审计日志、配置、Skill 元数据 | SQLite + 文件系统（宿主机存储） |
| **Skill 市场** | 官方 Skill 仓库索引、下载、安装管理 | 静态 JSON 索引 + 签名校验 |

## 5. 核心功能详解

### 5.1 桌宠交互系统

**目标**：让用户通过直觉化的拖拽和环形菜单与 AI 交互，降低学习成本。

**功能点**：
1. **浮动窗口**：
   - 始终置顶（可配置），可拖拽移动，右键菜单可隐藏/显示。
   - 状态指示：不同颜色/图标表示 AI 空闲、思考、执行任务、错误。
   - 点击主图标弹出环形菜单。

2. **环形菜单**：
   - 主菜单包含：对话、任务列表、Skill 面板、设置、远程状态等。
   - 拖拽文件/文件夹/Skill 包到桌宠时，弹出动态环形菜单，菜单项根据拖拽类型变化（如文件：归档/总结/重命名/移动/直接说需求）。
   - 支持二级菜单（如“更多操作”）。

3. **拖拽交互**：
   - 支持从文件管理器拖拽文件/文件夹到桌宠窗口任意位置。
   - 支持从 Skill 面板拖拽 Skill 到桌宠进行快速调用。
   - 拖拽 Skill 包到桌宠自动触发安装。

4. **Skill 库面板**：
   - 侧边栏或独立窗口，展示已安装 Skill 和官方库可安装 Skill。
   - 支持拖拽 Skill 到桌宠，支持一键安装/卸载。
   - 可查看 Skill 详情（权限、描述、版本）。

5. **资源优化**：
   - 用户可设置动画帧率（如 60fps / 30fps / 15fps）以平衡性能和体验。
   - 闲置时降低渲染开销。

**技术实现**：Electron 主进程管理窗口，渲染进程负责环形菜单和拖拽，通过 IPC 与后端（AI 容器）通信。

### 5.2 远程控制体系

**目标**：用户在任何地点都能安全地控制家中的 AI 助手，实时查看状态和结果。

**功能点**：
1. **内置穿透**：
   - AI 助手启动时自动连接自建中继服务器（或用户可自托管中继），获得一个临时公网地址（如 `https://xxx.relay.thedamnlif e.com`）。
   - 用户通过该地址访问 Web UI，无需配置路由器端口映射。
   - 中继服务器仅转发加密的指令和状态，不存储用户数据。

2. **Web UI**：
   - 响应式设计，适配手机、平板、PC 浏览器。
   - 功能完整：对话、查看任务状态、审计日志、批准/拒绝高风险操作、管理 Skill、查看桌宠状态等。
   - 实时推送：通过 WebSocket 获取 AI 思考过程、任务进度、结果。

3. **移动端 App**（可选）：
   - 若资源允许，提供 iOS/Android WebView 壳，或直接使用浏览器 PWA。
   - 支持推送通知（需与中继服务器配合）。

4. **命令行控制**：
   - 通过 REST API 提供命令行接口（例如 `damncli send "整理下载目录"`）。
   - 支持脚本化调用，便于集成到其他工具。

5. **安全机制**：
   - 单用户账户（用户名+密码），密码哈希存储于宿主机。
   - 所有远程通信使用 HTTPS/WSS 加密。
   - 高风险操作（如删除文件）仍需在远程 UI 上二次确认。

6. **审计合并**：
   - 远程操作日志与本地审计日志统一存储在宿主机 SQLite，便于追溯。

### 5.3 安全隔离与链接空间

**目标**：AI 运行在隔离环境中，通过“链接空间”与用户系统交互，确保用户系统安全。

**功能点**：
1. **AI 容器化**：
   - AI 助手（推理引擎、Skill Runtime、任务调度）运行在 Docker 容器中。
   - 容器资源限制（CPU、内存）可由用户配置。
   - 容器崩溃不影响宿主系统，且可自动重启。

2. **链接空间**：
   - 用户指定一个或多个“授权目录”，容器通过卷映射只读或读写访问这些目录。
   - 用户可配置“应用白名单”，容器可启动的应用程序仅限于白名单内的可执行文件。
   - 网络访问控制：容器可配置是否允许访问外网，以及域名/IP 白名单。
   - 剪贴板访问：可配置允许读写剪贴板。

3. **用户完全控制**：
   - 提供“控制面板”（UI 或命令行），用户可以：
     - 启动/停止 AI 容器
     - 重置容器（清空数据）
     - 清除所有用户数据（包括审计、配置，模型文件可选）
     - 卸载所有 Skill
     - 切换本地模型（若有多个）
     - 修改链接空间配置（增减授权目录、修改白名单）
     - 查看容器资源占用（CPU/内存）
     - 查看完整审计日志
     - 导出/导入配置

4. **默认拒绝原则**：
   - 所有对用户系统的访问默认禁止，必须通过链接空间显式授权。
   - Skill 安装时展示所需权限，用户批准后方可运行。

### 5.4 多设备同步（可选）

**目标**：同一用户在不同设备上使用 AI 助手时，数据保持一致。

**功能点**：
- 同步内容：对话历史、任务记录、Skill 列表及配置、链接空间配置（可选择性同步）。
- 同步方式：通过自建服务器（或用户自托管）同步，使用账户认证。
- 冲突处理：简单规则（最后写入优先）或用户介入。
- 离线优先：各设备本地保留完整数据，同步仅作为备份和跨设备迁移。

> 若资源紧张，V1.0 可先实现“手动导入导出配置”作为同步的替代，将自动同步推迟到 V1.1。

### 5.5 Skill 市场雏形

**目标**：用户可方便地发现和安装官方认证的 Skill。

**功能点**：
- 官方维护一个 Skill 索引（JSON），包含名称、描述、版本、权限声明、下载地址（签名）。
- Skill 面板中可浏览官方库，点击安装自动下载并校验签名。
- 安装后 Skill 进入本地，可拖拽调用。
- 后续版本可引入社区贡献和评分。

## 6. 离线优先与降级策略（V1.0 强化）

- **核心能力保持离线**：对话、本地推理、已安装 Skill、任务记录查询在断网时完全可用。
- **远程控制降级**：无外网时，Web UI 仅支持局域网访问（若用户配置了局域网访问）。
- **穿透降级**：若中继服务器不可用，可回退到用户自行配置的端口转发方式。
- **UI 明确提示**：网络状态（在线/离线/穿透中继状态）在桌宠和 Web UI 中清晰显示。

---

## 7. 数据与隐私（V1.0）

- 所有数据默认存储在宿主机，用户可随时一键清除。
- 中继服务器仅转发加密流量，不存储用户数据；若用户担心隐私，可自托管中继服务器。
- 敏感配置（如账户密码、API Key）使用系统安全存储（Windows Credential Manager / macOS Keychain）。
- 审计日志包含所有操作（包括远程操作），用户可追溯。

## 8. 技术架构建议（V1.0）

| 模块 | 技术选型 | 备注 |
|------|----------|------|
| AI 推理 | llama.cpp / Ollama | 优先保证 Windows 可用，支持多种模型格式 |
| 后端服务 | Go 或 Python（FastAPI） | 处理任务调度、容器管理、API 服务 |
| 容器化 | Docker | 确保隔离性，Windows 需安装 Docker Desktop |
| 桌宠前端 | Electron + React/Vue | 跨平台，易实现拖拽和环形菜单 |
| 远程穿透 | 自研中继（WebSocket）或集成 frp | 自研可简化，但需维护中继服务器 |
| 数据存储 | SQLite + 文件系统 | 简单可靠，便于备份 |
| 账户管理 | 本地 SQLite 存储密码哈希 | 单用户，密码加密存储 |
| 实时通信 | WebSocket | 推送状态和任务进度 |

## 9. 版本指标（V1.0 验收目标）

> 延续 V0.5 指标并补充远程相关指标。

- **任务成功率**：三场景任务成功率 ≥ 90%
- **失败可解释率**：失败案例中，用户能理解原因并完成修复/重试 ≥ 80%
- **离线可用比例**：核心流程离线可用覆盖 ≥ 95%
- **平均任务完成时长**：典型任务可在 1-3 分钟内完成
- **崩溃恢复成功率**：推理或 Runtime 异常后自动恢复且不丢上下文 ≥ 98%
- **远程控制可用率**：在典型网络环境下，远程连接成功率达到 95% 以上（不含用户网络故障）
- **桌宠交互响应时间**：环形菜单弹出 ≤ 0.2 秒，拖拽反馈 ≤ 0.1 秒
- **用户满意度**：内部测试用户对桌宠和远程控制的满意度 ≥ 4.5/5

## 11. 风险与应对

| 风险 | 严重程度 | 应对策略 |
|------|----------|----------|
| Docker 在 Windows 上稳定性问题 | 中 | 提供备选方案（受限子进程 + 用户账户隔离）；提供详细安装文档 |
| 内置穿透中继服务器成本与维护 | 中 | 初期自建轻量中继，开源代码允许用户自托管；若成本过高，可改为推荐用户使用免费穿透工具（如 ngrok）并内置启动脚本 |
| 桌宠环形菜单开发复杂度 | 中 | 采用成熟开源库（如 `react-radial-menu`），优先保证核心功能，动画效果可迭代优化 |
| 远程控制实时推送导致资源占用高 | 低 | WebSocket 连接空闲时降低推送频率；用户可关闭实时推送 |
| 多设备同步冲突处理复杂 | 中 | V1.0 先实现手动导入导出，自动同步作为可选功能，标记为实验性 |
| 用户对容器概念陌生 | 低 | 提供一键安装脚本，隐藏技术细节；控制面板中用“AI 独立空间”等友好术语 |

## 12. V1.0 Definition of Done（DoD）

以下全部满足才算 V1.0 完成：

- [ ] **桌宠**：浮动窗口可拖拽、隐藏；环形菜单正常弹出；支持拖拽文件/文件夹/Skill 包；Skill 面板可浏览官方库并安装/卸载。
- [ ] **远程控制**：通过内置穿透，在外网可访问 Web UI；Web UI 功能完整（对话、任务、审计、控制面板）；WebSocket 实时推送状态；命令行接口可用。
- [ ] **安全隔离**：AI 运行在 Docker 容器中；链接空间配置（授权目录、应用白名单）生效；用户完全控制面板（启动/停止、重置、清除数据等）可用。
- [ ] **多设备同步**（若实现）：至少两台设备间可同步配置和对话历史。
- [ ] **离线优先**：断网时核心功能仍可用；网络恢复后远程访问自动恢复。
- [ ] **三场景验收**：每场景至少 3 个典型任务可通过桌宠和远程分别完成，并记录审计。
- [ ] **性能指标**：满足第 9 章所有量化指标。
- [ ] **文档**：用户手册（含远程访问配置）、开发者文档（Skill 开发规范）、中继服务器自托管指南。
