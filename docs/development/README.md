# 🛠️ Development

开发指南 — 环境搭建、开发流程、编码规范、协作约定。

## 🎯 Role

开发者的 **入门与协作手册**，覆盖从环境配置到代码提交的完整开发流程，降低新成员上手成本。

```
新成员 ──► development/ ──► 开始贡献代码
              │
              ├── 环境搭建
              ├── 开发流程
              ├── 编码规范
              └── 协作约定
```

## ✅ Responsibility

- 开发环境搭建指南（Node / Python / Go / Rust）
- 本地开发流程（启动、调试、热重载）
- 编码规范与风格约定
- Git 工作流与分支策略
- PR / Code Review 规范
- 常见问题排查（Troubleshooting）

## 🚧 Boundaries

- 不包含架构或设计决策（见 `docs/architecture/`）
- 不包含 API 或协议定义
- 不包含部署运维流程（见 `infra/`）
- 不替代各模块内部的开发文档

## 📁 目录结构

```
development/
├── README.md            # 本文档
└── bootstrap.md         # 环境搭建与初始化指南
```
