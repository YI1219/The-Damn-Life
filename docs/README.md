# 📚 Docs

文档层 — 架构、协议、API 规范、开发指南。

## 🎯 Role

系统的**知识库**，确保架构决策、协议定义、开发规范有据可查。

## ✅ Responsibility

- 架构设计文档（`architecture/`）
- API 规范（`api/`）
- 事件协议定义（`protocols/`）
- Skill 开发规范（`skill-spec/`）
- 安全策略文档（`security/`）
- 开发指南（`development/`）
- Roadmap（`roadmap/`）

## 🚧 Boundaries

- 仅文档，不包含可执行代码
- 不作为配置源（配置在 `packages/config`）
