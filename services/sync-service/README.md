# 🔄 Sync Service

数据同步服务 — 多端状态一致性保障。

## 🎯 Role

系统的**同步协调层**，确保桌面端、Web 端、CLI 的任务状态、配置、审计日志在多设备间保持一致。

```
┌──────────┐     sync     ┌──────────────┐     sync     ┌──────────┐
│ App Shell│ ◄──────────► │ sync-service │ ◄──────────► │   Web    │
└──────────┘              └──────────────┘              └──────────┘
```

## ✅ Responsibility

- 任务状态跨端同步
- 配置变更推送
- 审计日志聚合
- 冲突检测与合并策略

## 🚧 Boundaries

- **不做** AI 编排或 Skill 调度（交给 `runtime-py`）
- **不做** 远程中继或穿透（交给 `relay-go`）
- **不做** 数据持久化层实现（仅协调同步流程）
- **不做** UI 渲染
